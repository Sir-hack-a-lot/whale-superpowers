# Receiving code review

1. Read ALL remarks first; group them (bug / style / discussion).
2. Bugs and valid points: fix immediately using the TDD cycle.
3. Discussion points: weigh, pick a stance, explain briefly in the reply.
4. Confirm per remark what was done (or why not), with a reference to the commit/line.
5. Afterwards: re-run tests, commit, and send the reviewer a closing message.
